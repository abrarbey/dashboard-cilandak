# dahboard-cilandak
Dashboard Kolaborasi. Lebih cepat. Lebih terukur. Pemantauan dan tindak lanjut peningkatan Pajak Daerah dalam satu ruang kerja. Pantau kinerja, tentukan objek prioritas, kelola surat penagihan, distribusikan tugas, dokumentasikan tindak lanjut, dan evaluasi hasil secara kolaboratif antara UPPPD, Kecamatan, dan Kelurahan.
